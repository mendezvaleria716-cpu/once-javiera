# Lo que aprendí sobre Desarrollo Backend

### 1. Fundamentos y Lenguajes
Lo primero que me aclaró el vídeo fue lo del lenguaje: hay mil opciones (**Java, C#, Python, Go, PHP...**) pero lo que realmente importa es tener sólidos los **fundamentos**:
* Variables
* Funciones
* Objetos
* Clases

Sin eso, cualquier lenguaje que elijas va a ser difícil.

### 2. Protocolo HTTP
Es la base de cómo funciona la web y no se puede ignorar. Incluye:
* Métodos (GET, POST, etc.)
* Códigos de estado
* Cookies

### 3. Frameworks y Diseño de APIs
Los **frameworks** evitan "reinventar la rueda":
* **Flexibles:** Express o Flask.
* **Estructurados:** Django o Laravel.

Sobre las **APIs**:
* **REST con JSON:** Lo más común.
* **Otras opciones:** GraphQL, gRPC y WebSockets (para tiempo real como chats).

### 4. Gestión de Datos
* **SQL:** Indispensable. **PostgreSQL** es la recomendación principal por ser de código abierto.
* **ORM:** Útiles para realizar consultas sin escribir SQL puro constantemente.
* **NoSQL:** **MongoDB** es ideal para datos más flexibles.
